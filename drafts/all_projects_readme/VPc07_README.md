# Система бронирования ресторана

Проект представляет собой систему бронирования столов в ресторане с возможностью управления пользователями, столами и бронированиями.

## Структура проекта

```
.
├── backend.py           # Бэкенд логика (CRUD операции)
├── postgres_driver.py   # Драйвер для работы с PostgreSQL
├── app.py               # GUI приложение на Tkinter (точка входа)
├── seed_data.py         # Скрипт заполнения тестовыми данными
├── requirements.txt     # Зависимости проекта
├── .env                 # Переменные окружения (не коммитить)
├── .env.example         # Пример переменных окружения
└── models/              # Модели данных
    ├── user.py          # Модель пользователя
    ├── table.py         # Модель стола
    └── booking.py       # Модель бронирования
```

## Модели данных

### User (Пользователь)

Модель для хранения информации о пользователях системы.

**Атрибуты:**
- `user_id` - ID пользователя (устанавливается БД)
- `email` - Email пользователя
- `password` - Пароль пользователя
- `first_name` - Имя пользователя
- `last_name` - Фамилия пользователя
- `phone` - Телефон пользователя (опционально)
- `role` - Роль: "Администратор", "Менеджер", "Пользователь"
- `status` - Статус: "Активен", "Неактивен", "Заблокирован", "Ожидает"
- `created_at` - Дата создания
- `updated_at` - Дата последнего обновления

### Table (Стол)

Модель для управления столами в ресторане.

**Атрибуты:**
- `table_id` - ID стола (устанавливается БД)
- `table_number` - Номер стола (уникальный)
- `capacity` - Вместимость (количество мест)
- `location` - Расположение: "Основной зал", "VIP зал", "Терраса", "Бар", "Приватная комната"
- `status` - Статус: "Доступен", "Занят", "Забронирован", "Неисправен", "На уборке"
- `description` - Описание стола
- `hourly_rate` - Стоимость бронирования за час
- `has_window_view` - Вид из окна (bool)
- `is_smoking_allowed` - Разрешено курение (bool)
- `created_at` - Дата создания
- `updated_at` - Дата обновления

### Booking (Бронирование)

Модель для управления бронированиями столов.

**Атрибуты:**
- `booking_id` - ID бронирования (устанавливается БД)
- `user_id` - ID пользователя (FK)
- `table_id` - ID стола (FK)
- `booking_date` - Дата бронирования
- `start_time` - Время начала
- `end_time` - Время окончания
- `guest_count` - Количество гостей
- `status` - Статус: "Ожидает", "Подтверждено", "Отменено", "Завершено", "Не явился"
- `special_requests` - Особые пожелания
- `contact_phone` - Контактный телефон
- `created_at` - Дата создания
- `updated_at` - Дата обновления

## Зависимости

Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

**Список зависимостей:**
- `psycopg2-binary` - Драйвер PostgreSQL для Python
- `python-dotenv` - Управление переменными окружения
- `sqlalchemy` - ORM для работы с базами данных

## Технологии

- **Python** - основной язык программирования
- **PostgreSQL** - система управления базами данных
- **dataclasses** - для определения моделей данных
- **psycopg2** - драйвер для работы с PostgreSQL
- **PostgreSQLDriver** - генерация SQL из моделей dataclass

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
3. Активируйте виртуальное окружение:
   ```bash
   # Windows
   venv\Scripts\activate
   
   # Linux/Mac
   source venv/bin/activate
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Настройте переменные окружения:
   ```bash
   # Скопируйте пример
   cp .env.example .env
   
   # Отредактируйте .env со своими данными
   ```

## Запуск приложения

### 1. Создание таблиц в базе данных

```bash
python backend.py
```

Это создаст таблицы `users`, `tables`, `bookings` автоматически на основе моделей данных.

### 2. Заполнение тестовыми данными (опционально)

```bash
python seed_data.py
```

Создаст тестовые данные:
- 6 пользователей (администратор, менеджер, 4 обычных пользователя)
- 12 столов (разные зоны ресторана)
- 7 бронирований (разные статусы)

### 3. Запуск GUI приложения

```bash
python app.py
```

Откроется окно приложения с тремя вкладками:
- **Пользователи** — управление пользователями системы
- **Столы** — управление столами ресторана
- **Бронирования** — создание и управление бронированиями

## Функциональность

### Backend (backend.py)

Полные CRUD операции для всех моделей:
- **Пользователи:** создание, чтение, обновление, удаление
- **Столы:** управление столовым фондом ресторана
- **Бронирования:** создание с проверкой доступности столов

Автоматическое выставление временных меток `created_at` и `updated_at`.

### GUI (app.py)

Трёхпанельный интерфейс на Tkinter:
- Формы добавления/редактирования
- Таблицы со списками записей
- Выпадающие списки для связанных полей
- Проверка доступности столов перед созданием бронирования

### PostgreSQL Driver (postgres_driver.py)

Автоматическая генерация SQL из dataclass моделей:
- Маппинг Python типов в PostgreSQL типы
- Создание таблиц по моделям
- Проверка существования таблиц
