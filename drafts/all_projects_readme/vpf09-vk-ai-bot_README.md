# VK AI Bot — интеллектуальный AI-помощник ВКонтакте

Асинхронный бот для ВКонтакте на Python с интеграцией LLM через ProxyAPI (OpenAI-совместимый API).
Поддерживает многодиалоговый режим, краткосрочную память (JSON-хранилище), 5 режимов общения
и удобный интерфейс на callback-кнопках.

## Возможности

- 🤖 Ответы через LLM (`AsyncOpenAI` + `chat.completions.create`, ProxyAPI)
- 💬 Несколько независимых диалогов: создание, переключение, переименование, удаление
- 🧠 Краткосрочная память: до 100 последних сообщений на диалог, хранение в JSON (папка `users/`)
- 🎭 5 режимов общения: Обычный помощник, Программист, Преподаватель, Бизнес-консультант, Дружелюбный собеседник
- ⌨️ Callback-кнопки VK: главное меню, список диалогов, настройки, помощь
- ⌨️ Имитация «бот печатает», разбивка длинных ответов (лимит 4000 символов)
- 🛡 Обработка ошибок сети/API с понятными fallback-сообщениями
- 📝 Логирование в консоль и файл `logs/bot.log`

## Запуск

### 1. Требования

- Python 3.11+ (проект разрабатывался и тестировался на 3.11/3.12)
- Токен сообщества ВКонтакте с правами «Управление сообществом» и включёнными «Возможностями ботов» (long polling)
- Ключ ProxyAPI (https://proxyapi.ru)

### 2. Установка

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS
pip install -r requirements.txt
```

### 3. Настройка .env

Скопируйте шаблон и заполните своими значениями:

```bash
copy .env.example .env        # Windows
# cp .env.example .env        # Linux/macOS
```

Содержимое `.env.example`:

```env
# VK Bot
VK_TOKEN=токен_сообщества
PROXY_API_KEY=ключ_proxyapi
OPENAI_BASE_URL=https://api.proxyapi.ru/v1
OPENAI_MODEL=openai/gpt-5.6-luna

# Лимиты
MAX_MESSAGE_LENGTH=4000
MAX_HISTORY_MESSAGES=100

# Хранилище
USERS_DIR=users

# Логирование (DEBUG / INFO / WARNING / ERROR)
LOG_LEVEL=INFO
```

> Файл `.env` добавлен в `.gitignore` и в репозиторий не попадает. Папки `users/` и `logs/`
> при этом коммитятся: в них хранятся JSON-файлы пользователей и логи работы бота.

### 4. Старт

```bash
python main.py
```

Напишите боту в личные сообщения сообщества **от своего имени** (не «от имени сообщества»)
и отправьте `начать` — придёт приветствие с кнопками.

## Архитектура

- **Слои**: `config` (настройки/промпты) → `models` (данные) → `storage` (персистентность) → `services` (бизнес-логика и AI) → `keyboards`/`bot` (интерфейс VK) → `main.py` (сборка и запуск).
- **Чистота**: AI-логика (`services/ai_service.py`) не знает о VK; VK-логика (`bot/handlers.py`) не знает о LLM.
- **Асинхронность**: весь код асинхронный; операции с диском выполняются через `asyncio.to_thread`.
- **Хранилище**: один JSON-файл на пользователя (`users/<user_id>.json`), атомарная запись через tmp-файл, кэш в памяти.

> **Важно про модель.** `gpt-5.6-luna` — reasoning-модель: она не поддерживает параметр
> `max_tokens` (используется `max_completion_tokens`) и нестандартную `temperature`.
> Часть бюджета токенов уходит на «рассуждения», поэтому лимит установлен в 4000
> (`MAX_COMPLETION_TOKENS` в `services/ai_service.py`). При смене модели проверьте её параметры.
