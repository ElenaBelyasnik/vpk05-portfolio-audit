# Напоминалка для Windows 11

Приложение на Python (`tkinter` + `SQLite`) для одноразовых и повторяющихся напоминаний с popup-окнами, звуком и системными уведомлениями Windows.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python -m reminders.main
```

Альтернативно:

```bash
cd reminders
python run_gui.py
```

Или двойной клик по `start_reminders.bat` в корне проекта.

## Основные возможности

- создание напоминаний с заголовком, описанием, датой и временем;
- быстрые кнопки времени (+1, +5, +15, +30, +45 минут, +1 час);
- повторяющиеся напоминания с интервалом:
  - каждые 15 минут;
  - каждые 30 минут;
  - каждый час;
  - каждый день;
- фоновая проверка напоминаний каждые 30 секунд;
- popup-окно и Windows Toast при срабатывании;
- звуковые сигналы при добавлении и срабатывании;
- фильтрация по статусу и ручные действия: `Готово`, `Отменено`, `Удалить`.

## Интерфейс

### Верхняя часть: добавление напоминания

- Поля: `Заголовок`, `Описание`, `Дата`, `Время`.
- Блок `Быстрое время`:
  - `Через 1 мин`
  - `Через 5 мин`
  - `Через 15 мин`
  - `Через 30 мин`
  - `Через 45 мин`
  - `Через 1 час`
- Блок повторения:
  - чекбокс `Повторять`;
  - выпадающий список интервала (15/30 мин, 1 час, 1 день).
- Кнопки: `Добавить напоминание`, `🔔 Тест уведомления`.

### Нижняя часть: список напоминаний

- Фильтр статусов: `Все`, `Ожидает`, `Готово`, `Просрочено`, `Отменено`.
- Таблица с колонками:
  - `ID`
  - `Заголовок`
  - `Описание`
  - `Дата/Время`
  - `Повтор` (Да/Нет)
  - `Интервал`
  - `Статус`
  - `Создано`
- Для повторяющихся задач:
  - в заголовке отображается маркер `🔁`;
  - текст строки подсвечивается тёмно-синим.
- Кнопки управления: `✅ Готово`, `❌ Отменено`, `🗑️ Удалить`, `🔄 Обновить`.

## Поведение повторяющихся напоминаний

- Одноразовое напоминание после срабатывания переводится в `Готово`.
- Повторяющееся после срабатывания не закрывается, а переносится на следующий интервал и остаётся в статусе `Ожидает`.
- Если приложение было выключено и пропущено несколько циклов, время корректируется на ближайший будущий интервал (без серии устаревших popup подряд).
- Повторяющиеся напоминания не переводятся в `Просрочено` обычной логикой просрочки.

## Статусы и цвета строк

| Статус | Цвет строки |
|--------|-------------|
| **Ожидает** | `#e8f5e9` (зелёный) |
| **Просрочено** | `#ffe6e6` (розовый) |
| **Готово** | `#fff8dc` (бежевый) |
| **Отменено** | `#d3d3d3` (серый) |

Для повторяющихся напоминаний цвет текста строки: `#0d47a1`.

## База данных

Файл базы: `reminders/reminders.db` (создаётся автоматически).

Таблица `reminders`:

- `id` — `INTEGER PRIMARY KEY AUTOINCREMENT`
- `title` — `TEXT NOT NULL`
- `description` — `TEXT`
- `due_datetime` — `TEXT NOT NULL` (ISO8601)
- `status` — `TEXT NOT NULL DEFAULT 'Ожидает'`
- `is_recurring` — `INTEGER NOT NULL DEFAULT 0` (0/1)
- `repeat_interval_minutes` — `INTEGER` (например 15, 30, 60, 1440)
- `created_at` — `TEXT NOT NULL` (ISO8601)

При старте применяется автоматическая миграция: если новых колонок ещё нет, они добавляются в существующую БД.

## Структура проекта

## Выход из приложения

При закрытии окна показывается подтверждение:

- `OK` — завершить приложение;
- `Отмена` — остаться в приложении.
