# AI Client Report Generator

Автоматическая генерация PDF-отчётов по транскрибации диалога с клиентом
с использованием LLM (через ProxyAPI — OpenAI-совместимый API) и HTML-шаблонов.

## Как это работает

1. Программа читает транскрибацию диалога из текстового файла.
2. Отправляет текст в LLM (модель `openai/gpt-5.6-luna` через ProxyAPI)
   и получает структурированный JSON:

   ```json
   {
     "client_name": "...",
     "topic": "...",
     "main_request": "...",
     "mood": "...",
     "next_steps": "...",
     "deadline": "...",
     "budget": "...",
     "requirements": "..."
   }
   ```

3. Подставляет данные в HTML-шаблон выбранного стиля через **Jinja2**
   (3 стиля: classic, modern, corporate).
4. Конвертирует HTML в PDF через **WeasyPrint**.
5. Сохраняет PDF в папку `reports/` с именем
   `report_<ИмяКлиента>_<стиль>_<дата>_<время>.pdf`.

Также отчёты можно генерировать через **Telegram-бота** (см. раздел
«Telegram-бот» ниже).

## Установка

Требуется **Python 3.12+**.

1. Создать виртуальное окружение:

   ```bash
   python -m venv venv
   ```

2. Активировать его:

   - **Windows:** `venv\Scripts\activate`
   - **Linux/macOS:** `source venv/bin/activate`

3. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создать файл `.env` из примера и заполнить своими ключами:

   ```bash
   cp .env.example .env   # Windows: copy .env.example .env
   ```

   Содержимое `.env`:

   ```env
   PROXY_API_KEY=ваш_ключ_proxyapi
   OPENAI_BASE_URL=https://api.proxyapi.ru/v1
   OPENAI_MODEL=openai/gpt-5.6-luna
   LOG_LEVEL=INFO
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   TELEGRAM_PROXY_URL=http://127.0.0.1:10809
   TELEGRAM_TIMEOUT=30
   ```

   `PROXY_API_KEY` обязателен для обоих режимов; `TELEGRAM_BOT_TOKEN` —
   только для запуска Telegram-бота.

## Использование

```bash
python main.py examples/example_dialog.txt
```

После чтения файла программа предложит выбрать стиль отчёта:

```
Выберите стиль отчёта:
  1. Классический (classic)
  2. Современный (modern)
  3. Корпоративный (corporate)
Введите номер (1-3): 2

Выбран стиль: Современный
```

Можно ввести как номер (1–3), так и имя стиля (`classic` / `modern` / `corporate`).

После успешного выполнения в консоли появится сообщение:

```
Отчёт успешно создан: reports/report_<ИмяКлиента>_<стиль>_<дата>_<время>.pdf
```

Пример: `reports/report_Анна_Смирнова_modern_20260920_004844.pdf`

## Стили отчётов

| Стиль | Шаблон | Описание |
|---|---|---|
| `classic` (Классический) | `templates/report_template_classic.html` | Деловой, строгий шрифт с засечками, синие и серые тона, двойные линии-разделители |
| `modern` (Современный) | `templates/report_template_modern.html` | Минимализм, чёрно-белая гамма, крупная типографика, жёлтый акцент настроения |
| `corporate` (Корпоративный) | `templates/report_template_corporate.html` | Фирменные цвета, плашка-логотип, градиентная шапка, карточки-блоки с рамками |

## Telegram-бот

Помимо консольного режима, проект включает Telegram-бота с той же логикой
генерации отчётов. Бот принимает .txt файл с транскрибацией диалога,
анализирует его через LLM и возвращает готовый PDF прямо в чат.

### Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие, описание возможностей и inline-кнопки выбора стиля (Classic / Modern / Corporate) |
| `/help` | Подробная справка: как отправить файл, какие форматы принимаются, какие стили доступны |

### Как пользоваться ботом

1. Отправьте боту `/start` и выберите стиль отчёта кнопкой
   (если не выбирать — будет использован Classic).
2. Отправьте .txt файл с транскрибацией диалога.
3. Бот обработает диалог и пришлёт PDF-отчёт в чат.
4. Для нового отчёта просто отправьте следующий .txt файл.

### Запуск бота

Для работы бота нужен токен — переменная `TELEGRAM_BOT_TOKEN` в `.env`
(получить у [@BotFather](https://t.me/BotFather)):

```env
TELEGRAM_BOT_TOKEN=1234567890:ABC-ваш_токен
# Прокси для доступа к Telegram API (пусто или удалить — без прокси)
TELEGRAM_PROXY_URL=http://127.0.0.1:10809
TELEGRAM_TIMEOUT=30
```

Запуск:

```bash
python bot.py
```

Бот работает в режиме long polling и обрабатывает сообщения до остановки
(Ctrl+C). Все этапы (получение файла, выбор стиля, запрос к LLM, генерация
PDF, отправка пользователю) логируются в консоль и `logs/app.log`.

## Логирование

Логи пишутся одновременно в **консоль** и в файл **logs/app.log**.
Уровень задаётся переменной `LOG_LEVEL` в `.env` (по умолчанию `INFO`).

## Обработка ошибок

| Ситуация | Поведение программы |
|---|---|
| Файл не найден | Понятное сообщение в консоль, код выхода 1 |
| Файл пуст | Сообщение об ошибке |
| Ошибка API | До 3 повторных попыток, затем fallback с заглушками + логирование |
| Ошибка парсинга JSON | Попытка извлечь JSON из текста ответа (markdown-блок, `{...}`) + логирование |
| Ошибка генерации PDF | Логирование + сообщение об ошибке |
| Telegram: файл не .txt | «Пожалуйста, отправьте текстовый файл (.txt)» |
| Telegram: ошибка API / PDF | Понятное сообщение в чат + логирование |

## Технологии

- **Python 3.12**
- **OpenAI SDK** — запросы к LLM через ProxyAPI
- **Jinja2** — HTML-шаблоны
- **WeasyPrint** — конвертация HTML → PDF
- **python-dotenv** — переменные окружения из `.env`
- **pyTelegramBotAPI** — Telegram-бот
- **Pillow / requests** — опционально, для работы с изображениями
