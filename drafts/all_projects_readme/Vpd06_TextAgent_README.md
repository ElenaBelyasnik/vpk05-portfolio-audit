# 🤖 Умный текстовый помощник

Консольное приложение для взаимодействия с AI-моделями через **ProxyAPI**.
Поддерживает обычную и «думающую» модель с отображением процесса размышлений.

---

## 📋 Возможности

- 💬 Диалог с сохранением контекста
- 🔄 Переключение между моделями во время сессии
- 💭 Отображение размышлений (thinking) для Claude Sonnet 4.5
- 🎨 Цветной CLI-вывод
- 📜 Просмотр полной истории диалога
- 🤖 По умолчанию — думающая модель

---

## 📦 Требования

- Python 3.8+
- API-ключ ProxyAPI

---

## 🚀 Установка

### 1. Клонирование и подготовка

```bash
git clone <repository-url>
cd Vpd06_TextAgent
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация окружения

**Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**
```cmd
venv\Scripts\activate.bat
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## ⚙️ Настройка

Скопируйте шаблон и заполните ключи:

```bash
copy .env.example .env
```

Откройте `.env` и укажите свои API-ключи ProxyAPI:

```env
OPENAI_API_KEY=ваш_ключ_proxyapi
OPENAI_MODEL=gpt-4.1-mini
ANTHROPIC_API_KEY=ваш_ключ_proxyapi
ANTHROPIC_MODEL=claude-sonnet-4-5
```

> **Важно:** Замените `ваш_ключ_proxyapi` на реальный ключ, полученный на [proxyapi.ru](https://proxyapi.ru).
> Файл `.env` не попадает в Git — используйте `.env.example` как шаблон.

## 🎮 Использование

### При запуске

Приложение автоматически запускается с **думающей моделью** `claude-sonnet-4-5`.

### Команды во время сессии

| Команда | Описание |
|---------|----------|
| *текст* | Отправить сообщение модели |
| `exit` | Завершить сессию и показать историю |
| `switch` | Переключить модель на лету |
| `history` | Показать полную историю диалога |

### Выход

Нажмите `Ctrl+C` или введите `exit` для завершения сессии.
После выхода будет выведена полная история диалога.
