# Telegram Notes Bot

Telegram-бот для управления заметками с напоминаниями на aiogram 3.x.

## Возможности

- 📝 Создание заметок с дедлайнами
- ⏰ Напоминания в момент наступления события (настраивается)
- 📋 Просмотр всех заметок (активные, выполненные, просроченные)
- 🔄 Откладывание задач на удобное время (30 мин, 1-4 ч, 1-2 дн, 1 нед)
- 🎨 Красивый интерфейс с листанием заметок
- 📊 Статусы заметок: Активна, Выполнена, Просрочено, Неактивна
- 🔧 Настройка времени напоминания через файл .env
- 🔔 Интерактивные уведомления с кнопками действий

## Статусы заметок

| Статус | Описание |
|--------|----------|
| ⏳ Активна | Заметка активна, напоминание ещё не отправлено |
| ✅ Выполнена | Напоминание отправлено автоматически |
| ⌛️ Неактивна | Отмечена вручную как выполненная |
| ⚠️ Просрочено | Дедлайн прошёл |
| ❌ Удалена | Заметка удалена |

## Напоминания

При срабатывании напоминания бот отправляет сообщение с кнопками:

```
⏰ Напоминание!

📝 Задача: Текст заметки
⏱️ Дедлайн: ⚡️ 15.05.2026 14:13 (через 0 мин.)
До истечения срока осталось менее 0 минут!

Выберите действие:
```

**Кнопки:**
- ✅ Выполнено - меняет статус на `COMPLETED`
- ⏰ Отложить - показывает выбор времени откладывания
- ❌ Удалить - удаляет заметку

### Откладывание задачи

После нажатия "Отложить" появляются кнопки:

**Ряд 1:**
- ⏰ 30 минут
- ⏰ 2 часа
- 📆 1 день

**Ряд 2:**
- ⏰ 1 час
- ⏰ 4 часа
- 📆 2 дня

**Ряд 3:**
- 📆 1 неделя

После выбора времени задача откладывается на указанное время и статус меняется на `ACTIVE`.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` с токеном бота и настройками:
```
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather

# Время напоминания в минутах до дедлайна
# 0 = в момент наступления события (для тестирования)
# 30 = за 30 минут до дедлайна (стандарт)
REMINDER_TIME_MINUTES=0
```

3. Запустите бота:
```bash
python bot.py
```

## Использование

1. Отправьте `/start` для начала работы
2. Создавайте заметки с дедлайнами:
   - Нажмите "📝 Создать заметку"
   - Введите текст заметки
   - Введите дедлайн в формате:
     - `ДД.ММ.ГГГГ ЧЧ:ММ` (например: `25.12.2024 15:30`)
     - `через X минут/часов/дней` (например: `через 2 минуты`)
3. Просматривайте заметки через "📋 Мои заметки"
4. Получайте уведомления с кнопками действий
5. Управляйте задачами: выполняйте, удаляйте или откладывайте

## Тестирование бота

### Быстрое тестирование

1. **Запустите бота:**
```bash
python bot.py
```

2. **В Telegram отправьте `/start`**

3. **Создайте тестовую заметку с коротким дедлайном:**
   - Нажмите "📝 Создать заметку"
   - Введите текст: `Тестовая заметка`
   - Введите дедлайн: `через 2 минуты`

4. **Подождите 2 минуты:**
   - Бот пришлёт уведомление с кнопками
   - Статус заметки изменится на `✅ Выполнена`

5. **Проверьте список заметок:**
   - Нажмите "📋 Мои заметки"
   - Должна отображаться ваша заметка со статусом

### Проверка откладывания

1. Создайте заметку с дедлайном "через 1 минуту"
2. Дождитесь уведомления
3. Нажмите "⏰ Отложить"
4. Выберите "⏰ 30 минут"
5. Должно появиться сообщение: "Отложено на 30 мин:" с новым дедлайном

### Проверка всех статусов

| Действие | Ожидаемый результат |
|----------|---------------------|
| Создать заметку | Статус `⏳ Активна` |
| Дождаться напоминания | Статус `✅ Выполнена` |
| Нажать "✅ Выполнено" вручную | Статус `⌛️ Неактивна` |
| Подождать до просрочки | Статус `⚠️ Просрочено` |
| Нажать "❌ Удалить" | Заметка исчезает из списка |

### Сортировка заметок

Заметки автоматически сортируются по дедлайну от более позднего к более раннему.

### Настройка времени напоминания

В файле `.env` можно изменить время напоминания:

```
# Для тестирования (в момент события)
REMINDER_TIME_MINUTES=0

# Для реального использования (за 30 минут)
REMINDER_TIME_MINUTES=30
```

После изменения настройка применяется после перезапуска бота.

## Структура проекта

```
telegram_notes_bot/
├── bot.py           # Основной файл бота
├── models.py        # Модели данных (Note, NoteStatus)
├── storage.py       # Хранилище заметок (JSON)
├── keyboards.py     # Клавиатуры (кнопки)
├── handlers.py      # Обработчики сообщений
├── scheduler.py     # Планировщик напоминаний
├── utils.py         # Утилиты (парсинг дедлайнов)
├── requirements.txt # Зависимости
├── .env             # Настройки (токен, время напоминания)
└── README.md        # Документация
```

## Файлы

- **bot.py** - Запуск бота, настройка прокси, отправка уведомлений с кнопками
- **models.py** - Модель заметки с полями: id, текст, дедлайн, статус, user_id
- **storage.py** - Хранение в JSON файле, управление заметками и chat_id пользователей
- **handlers.py** - Обработка команд и кнопок, отображение заметок, откладывание
- **keyboards.py** - Генерация кнопок для интерфейса и напоминаний
- **scheduler.py** - Планировщик для отложенных задач
- **utils.py** - Парсинг дедлайнов ("через X минут", "ДД.ММ.ГГГГ ЧЧ:ММ")

## Зависимости

Смотрите `requirements.txt`:
- aiogram >= 3.x
- python-dotenv
- aiohttp-socks (опционально, для прокси)

## Прокси (опционально)

Если Telegram заблокирован, настройте прокси в `.env`:

```
# SOCKS5 прокси
TELEGRAM_PROXY_URL=socks5://host:port

# HTTP прокси
TELEGRAM_PROXY_URL=http://host:port
```
