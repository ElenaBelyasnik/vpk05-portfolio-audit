новой# Lead Intake MVP

Микросервис для приёма заявок через webhook с сохранением в SQLite.

## Запуск

1. Создать виртуальное окружение:
   ```
   python -m venv venv
   ```

2. Активировать окружение:
   - Windows: `.\venv\Scripts\activate`
   - Linux/macOS: `source venv/bin/activate`

3. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```

4. Запустить сервер из папки backend:
   ```
   cd backend
   uvicorn main:app --reload
   ```

5. Открыть в браузере:
   - Swagger UI: `http://127.0.0.1:8000/docs`
   - HTML-форма: `http://127.0.0.1:8000/form`
   - Telegram-бот: запустится автоматически (см. ниже)

## Проверка

### Swagger UI
Доступен по адресу `/docs`. Можно отправить тестовый POST-запрос через интерфейс.

### HTML-форма
Доступна по адресу `/form`. Можно заполнить поля и отправить заявку через браузер.

### Telegram-бот
Бот запускается автоматически вместе с сервером.

**Как получить токен:**
1. Откройте в Telegram бота `@BotFather`
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен
5. Вставьте в файл `.env`: `TELEGRAM_BOT_TOKEN=ваш_токен`

**Как использовать:**
1. Найдите бота в Telegram по username
2. Отправьте `/start`
3. Напишите текст заявки
4. Получите подтверждение с ID заявки

**Важно:** Telegram-бот использует тот же эндпоинт `/lead`, что и HTML-форма и API. Все заявки проходят через единую функцию `save_lead()` в `lead_service.py`, которая сохраняет данные в БД, логирует их и отправляет email-уведомление.

### Лог-файлы
Сервис ведёт два лог-файла в папке `logs/`:

**logs/events.log** — успешные заявки:
```
[2026-07-03 12:34:56] New lead saved: id=1, name=Иван Петров, contact=+79990000000, comment=Хочу консультацию
```

**logs/errors.log** — ошибки (валидация, БД):
```
2026-07-03 21:21:42 | ERROR | Validation error: contact is required | Не указан ни один контактный телефон: phone, email, telegram_contact | name=Царевна-лягушка
2026-07-03 21:23:15 | ERROR | Validation error: phone: Номер телефона должен быть в формате +7XXXXXXXXXX (11 цифр) | name=Баба-Яга
2026-07-03 21:25:30 | ERROR | Database error: IntegrityError: table leads has no column named contact | name=Error
```

Формат записей ошибок: `дата | время | уровень | тип ошибки | детали`

Для ошибок валидации (422) логируется:
- Системное сообщение на английском (описание ошибки Pydantic)
- Русское описание с указанием конкретных полей

### Email-уведомления
Сервис может отправлять уведомления о новых заявках на email менеджера.

**Настройка:**
1. В файле `.env` заполните переменные:
   - `SMTP_HOST` — адрес SMTP-сервера (например, `smtp.mail.ru`)
   - `SMTP_PORT` — порт (например, `465` для SSL)
   - `SMTP_USER` — логин почты, от чьего имени отправлять
   - `SMTP_PASSWORD` — пароль приложения (не обычный пароль от почты!)
   - `NOTIFICATION_EMAIL` — адрес, куда слать уведомления (например, `...@yandex.ru`)
2. Перезапустите сервер.

**Формат уведомлений:**

**Тема письма:** `Новая заявка на сайте, Иван Петров` или `Новая заявка в Telegram, Елена`

**Заявка с сайта:**
```
Новая заявка!
----------------
ID: 1
Имя: Иван Петров
Телефон: +79990000000
Email: ivan@example.com
Источник: web
Заявка: Хочу консультацию
Комментарий: Не указано
```

**Заявка из Telegram:**
```
Новая заявка!
----------------
ID: 2
Имя: Елена
Telegram: @demo_user
Источник: telegram
Заявка: Хочу новую шубу
Комментарий: Не указано
```

**Заявка из Telegram:**
```
Новая заявка!
----------------
ID: 2
Имя: Елена
Telegram: @demo_user
Источник: telegram
Заявка: Хочу новую шубу
Комментарий: Не указано
```

> **Важно:** Для Telegram-заявок показывается только Telegram-контакт, строки Телефон и Email не отображаются.

**Получение пароля приложения Mail.ru:**
1. Зайдите в почту: https://mail.ru/
2. Нажмите на аватар → **Настройки** → **Все настройки**
3. Найдите раздел **Пароли приложений**
4. Создайте пароль, дайте имя (например, "Lead MVP")
5. Скопируйте сгенерированный пароль

**Получение пароля приложения Яндекс:**
1. Зайдите в аккаунт: https://id.yandex.ru/
2. Перейдите в **Безопасность** → **Пароли приложений**
3. Выберите **Почта**, дайте имя (например, "Lead MVP")
4. Скопируйте сгенерированный пароль (16 символов)

**Важно:** Яндекс может блокировать SMTP для новых/тестовых аккаунтов. Используйте основной аккаунт для отправки писем.

**Рекомендация:** используйте основную почту для отправки, а уведомления отправляйте на личную почту менеджера (...@yandex.ru, ...@mail.ru и т.д.).

Если переменная `NOTIFICATION_EMAIL` не указана, уведомления отправляться не будут, но это не повлияет на работу сервиса.

### cURL / PowerShell

**Linux/macOS:**
```bash
curl -X POST "http://127.0.0.1:8000/lead" \
     -H "Content-Type: application/json" \
     -d '{"name":"Иван","contact":"ivan@example.com","source":"web","comment":"Тест"}'
```

**Windows (PowerShell):**
```powershell
$body = '{"name":"Иван","contact":"ivan@example.com","source":"web","comment":"Тест"}'
Invoke-RestMethod -Uri "http://127.0.0.1:8000/lead" -Method Post `
  -ContentType "application/json; charset=utf-8" `
  -Body $body
```

**Важно:** Всегда указывайте `charset=utf-8` в `Content-Type`, иначе русские символы могут сохраниться как `???`.

**Ожидаемый ответ:**
```json
{"status": "ok", "id": 1}
```

## Тестирование

Для автоматической проверки работы эндпоинта `/lead` используются скрипты из папки `tests/`.

### Как запустить тесты

1. Убедитесь, что сервер запущен:
   ```bash
   cd backend
   uvicorn main:app --reload
   ```

2. В другом терминале запустите тесты:
   ```bash
   python tests/run_tests.py
   ```

### Что тестируется

- Валидные заявки с разными комбинациями контактов (телефон, email, telegram)
- Ошибки валидации (отсутствие контактов, невалидный телефон)
- Корректность обработки Telegram-контактов

### Результат

Тесты выводят цветной отчёт с именами героев сказок (в качестве тестовых данных) и статусами:
- ✅ `PASS` — тест пройден
- ❌ `FAIL` — тест не пройден

В конце выводится сводка: `Пройдено X из Y тестов`.

## Структура БД

Таблица `leads`:
| Колонка          | Тип                    | Описание              |
|-----------------|------------------------|-----------------------|
| `id`            | INTEGER PRIMARY KEY    | Уникальный идентификатор |
| `created_at`    | TIMESTAMP              | Время создания (МСК)   |
| `name`          | TEXT                   | Имя заявителя          |
| `phone`         | TEXT                   | Телефон               |
| `email`         | TEXT                   | Email                 |
| `telegram_contact` | TEXT                | Контакт из Telegram (@username) |
| `source`        | TEXT                   | Источник заявки        |
| `description`   | TEXT                   | Текст заявки (опционально) |
| `comment`       | TEXT                   | Комментарий            |

## API

### POST /lead
Приём новой заявки.

**Тело запроса:**
```json
{
  "name": "Иван",
  "phone": "+79991234567",
  "email": "ivan@example.com",
  "source": "web",
  "comment": "Хочу узнать подробнее",
  "description": "Хочу купить мед"
}
```

**Валидация:**
- `name` — обязательно
- `phone` или `email` — хотя бы один обязателен (возвращает HTTP 400, если не указан)
- `phone` — если указан, должен быть в формате +7XXXXXXXXXX (11 цифр)
- `email` — если указан, должен быть корректным email

**Ответы:**
- `200` — успех: `{"status": "ok", "id": 1}`
- `400` — ошибка валидации: `{"detail": "contact is required"}`
- `422` — ошибка формата JSON или телефона
- `500` — ошибка базы данных

### GET /

**Ответ:**

```json
{"message": "Lead Intake MVP is running"}
```

### GET /form
HTML-форма для ручного ввода заявок.

**Открывается в браузере:**
```
http://127.0.0.1:8000/form
```

**Возможности:**

- Отображение результата с ID заявки
