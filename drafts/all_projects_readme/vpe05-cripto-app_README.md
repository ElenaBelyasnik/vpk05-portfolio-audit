# Криптовалютная биржа — эмуляция бэкэнда

Приложение эмулирует работу реальной криптовалютной биржи, генерируя случайные события: ордера, сделки, API-запросы, WebSocket-события, активность пользователей, пополнения/выводы и системные события безопасности. Все логи отправляются в Grafana Loki.

## Запуск приложения

### 1. Активация виртуального окружения

```powershell
.venv\Scripts\Activate.ps1
```

### 2. Запуск приложения

```powershell
python main.py
```

### 3. Остановка

Нажмите `Ctrl+C` для остановки приложения.

## Настройка дашборда Grafana

Панель **"Распределение логов по уровням"** (Pie chart):
- **Query A (INFO):** `count_over_time({job="api", level="INFO"}[1h])`
- **Query B (WARNING):** `count_over_time({job="api", level="WARNING"}[1h])`
- **Query C (ERROR):** `count_over_time({job="api", level="ERROR"}[1h])`
- **Transform:** Reduce → Mode: Series to rows, Calculations: Total
- **Overrides:** Display Name — "Информация", "Предупреждение", "Ошибка"
- **Query Options:** Max data points: 50, Interval: 1m, Relative time: 1h

Панель **"Логи"** (таблица):
- Использует переменную `App` для фильтрации по job
- Показывает последние логи с временными метками

## Что генерирует приложение

- **Торговая активность**: книги ордеров (bid/ask), исполнение сделок, отмена ордеров, обновление цен для 12 торговых пар
- **API запросы**: GET/POST к эндпоинтам биржи с разными статусами (200, 400, 401, 429, 500) и задержками
- **WebSocket события**: candle updates, depth updates, ticker updates, order book spread
- **Действия пользователей**: 20 пользователей совершают покупки, продажи, пополнения, выводы, проверку баланса, смену IP
- **Безопасность**: brute-force атаки, подозрительные входы, алерты на вывод, DDoS-детекция
- **Системные события**: нагрузка сервера, очередь ордеров, резервное копирование, rate limiter, SSL сертификаты

События генерируются каждые 2–8 секунд со случайными задержками.
