# 🤖 AI-Агент

Локальный AI-агент на Python с использованием OpenAI-совместимого API (ProxyAPI).

## 📋 Возможности

| Инструмент | Описание |
|---|---|
| 🔍 **Веб-поиск** | Поиск в интернете через DuckDuckGo |
| 🌤 **Погода** | Текущая погода для любого города (Open-Meteo) |
| 💰 **Криптовалюты** | Курсы Bitcoin, Ethereum и других (CoinGecko) |
| 💱 **Валюты** | Курсы фиатных валют (ЦБ РФ — cbr-xml-daily.ru) |
| 📱 **QR-коды** | Генерация QR-кодов из текста/URL |
| 📄 **Файлы** | Чтение и запись файлов в папке agent/ |
| 🧠 **Память** | Долговременная память (memory.json) |

## 📱 Telegram-бот

Проект включает Telegram-бота с тем же функционалом, что и CLI-версия.

| Команда | Действие |
|---|---|
| *(любой текст)* | Отправить запрос агенту |
| `/start` | Приветствие и список возможностей |
| `/help` | Справка по командам |
| `/clear` | Очистить историю диалога |

### Создание бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Получите токен и вставьте в `.env`

## 🚀 Быстрый старт

### 1. Требования

- **Python 3.11.x** (обязательно!)
- Активный API-ключ [ProxyAPI](https://proxyapi.ru)
- Для QR-кодов: `pip install qrcode pillow` (добавлено в requirements.txt)

### 2. Установка

```bash
# Создаём виртуальное окружение
python -m venv venv

# Активируем
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt
```

### 3. Настройка

Откройте файл `.env` и вставьте свои ключи:

```env
OPENAI_API_KEY=ваш_ключ_proxyapi
OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1
OPENAI_MODEL=gpt-5-6-luna
TEMPERATURE=0.2
LOG_LEVEL=INFO
BOT_TOKEN=ваш_токен_бота_от_BotFather
```

### 4. Запуск CLI-версии

```bash
python run.py
```

### 5. Запуск Telegram-бота

```bash
python telegram_bot.py
```

## 📁 Структура проекта

```
vpf07-ai-agent/
├── .env                    # Конфигурация (API-ключ, BOT_TOKEN)
├── .env.example            # Шаблон конфигурации
├── .gitignore              # Игнорируемые файлы
├── requirements.txt        # Зависимости Python
├── run.py                  # Точка входа (CLI)
├── telegram_bot.py         # Точка входа (Telegram-бот)
├── README.md               # Этот файл
├── ProgressOfWork.md       # Ход работ
└── agent/
    ├── __init__.py         # Модуль агента
    ├── agent.py            # Основная логика (CLI)
    ├── tools.py            # Инструменты
    ├── memory.json         # Долговременная память
    └── agent.log           # Лог-файл (создаётся автоматически)
```

## 📝 Логи

Все действия агента логируются в `agent/agent.log`.
Уровень логирования настраивается через `LOG_LEVEL` в `.env`.

## ⚠️ Важно

- Используйте **Python 3.11.x** — langchain не совместим с 3.12+
- Все файлы для инструментов доступны только в папке `agent/`
- Память хранит последние 50 записей

## 🧪 Тестовые сценарии

Выполняйте тесты последовательно в запущенном агенте.

| № | Действие | Ожидаемый результат |
|---|---|---|
| **1** | `Привет. Что ты умеешь?` | Агент отвечает на русском, перечисляет инструменты (поиск, погода, крипто, файлы, память). |
| **2** | `Найди информацию о Красной площади в Москве.` | Краткий ответ с фактами: год постройки, архитектор, интересные факты. |
| **3** | `Какая сегодня погода в Санкт-Петербурге?` | Температура, скорость ветра, описание погоды (напр. «+12°C, облачно, ветер 5 м/с»). |
| **4** | `Сколько сейчас стоит 1 Bitcoin в долларах?` | Актуальная цена BTC в USD (напр. «1 BTC = 67 400 USD»). |
| **5** | `А сколько Ethereum?` *(сразу после запроса про Bitcoin)* | Агент понимает контекст и возвращает цену ETH в USD. |
| **6** | `Создай файл test.txt и запиши в него текст "Привет, мир! Это тест агента."` | Файл `test.txt` создан в папке `agent/`, агент сообщает об успехе. |
| **7** | `Прочитай файл test.txt и покажи его содержимое.` | Выведено содержимое: «Привет, мир! Это тест агента.» |
| **8** | `Какой был мой первый вопрос в этом диалоге?` | Агент обращается к `memory.json` и называет первый вопрос. |
| **9** | `Какой курс евро к рублю сейчас?` | Актуальный курс EUR/RUB (напр. «1 EUR = 98.50 RUB»). |
| **10** | `Сгенерируй QR-код для текста "Привет, мир!"` | Файл QR-кода создан в папке `agent/`, агент сообщает путь. |
| **11** | `Сколько сегодня стоит нефть?` | Агент сообщает, что такого инструмента нет, предлагает уточнить. |
| **12** | Откройте `agent.log` после выполнения тестов | В логе есть записи о каждом шаге: запрос → инструмент → результат. |
| **13** | `exit` | Агент завершает работу (цикл диалога прерывается). |
