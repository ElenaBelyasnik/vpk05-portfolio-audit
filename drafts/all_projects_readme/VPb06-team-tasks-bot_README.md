# Telegram-бот для управления задачами команды

Бот для хранения и управления задачами команды с использованием Telegram.

## Функционал

Бот поддерживает следующие команды:

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и справка по командам |
| `/add` | Добавить новую задачу (с выбором категории и статуса) |
| `/list` | Показать все задачи (ID, текст, автор, статус, категория, дата) |
| `/list_csv` | Выгрузить все задачи в CSV файл |

### Новые возможности

- **Категории задач:** работа, личное, обучение, здоровье, семья, финансы
- **Статусы задач:** в планах, в работе, выполнена
- **Интерактивный выбор:** категории и статус выбираются через кнопки

## Требования

- Python 3.8+
- Telegram Bot Token (получить у @BotFather)

## Установка и запуск

### 1. Создать виртуальное окружение

```powershell
# Создание виртуального окружения
python -m venv venv

# Активация (PowerShell)
.\venv\Scripts\Activate.ps1
```

### 2. Установить зависимости

```powershell
pip install -r requirements.txt
```

### 3. Настроить токен бота

Создайте файл `.env` в корневой директории и добавьте токен:

```
BOT_TOKEN=ваш_токен_бота_здесь
```

> Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram.

### 4. Запустить бота

```powershell
python main.py
```

## Примеры использования

### Добавление задачи

1. Отправьте команду `/add`
2. Бот запросит текст задачи
3. Отправьте текст задачи
4. Выберите категорию из предложенных кнопок
5. Выберите статус из предложенных кнопок
6. Бот подтвердит добавление с ID задачи

### Просмотр задач

Отправьте команду `/list` — бот покажет все задачи в формате:
```
1. Сделать презентацию (от Иван, в работе, работа, 2024-01-15 14:30)
2. Подготовить отчёт (от Мария, в планах, личное, 2024-01-15 15:45)
```

### Экспорт в CSV

Отправьте команду `/list_csv` — бот отправит файл `tasks.csv` со всеми задачами.

CSV файл содержит колонки:
- ID
- Текст задачи
- Пользователь
- Статус
- Категория
- Дата создания

## База данных

Бот использует SQLite3 для хранения задач. Файл базы данных `tasks.db` создаётся автоматически в корневой директории.

Структура таблицы `tasks`:
- `id` — уникальный идентификатор
- `text` — текст задачи
- `user` — имя пользователя, создавшего задачу
- `status` — статус задачи (в планах, в работе, выполнена)
- `category` — категория задачи (работа, личное, обучение, здоровье, семья, финансы)
- `created_at` — дата и время создания
