# HTTP Тестовый Модуль

Тестовый модуль для выполнения HTTP-запросов с удобным консольным интерфейсом.

## Возможности

- **GET-запросы по URL** — произвольные GET-запросы с поддержкой query-параметров
- **Информация о стране** — получение данных о населении страны с красивым цветным выводом
- **Случайная собака** — получение случайного изображения собаки из API
- **Цветной вывод** — использование библиотеки `colorama` для красивого форматирования

## Требования

- Python 3.8+
- virtualenv (рекомендуется)

## Установка

1. Создайте виртуальное окружение:
```powershell
python -m venv venv
```

2. Активируйте виртуальное окружение:
```powershell
.\venv\Scripts\Activate.ps1
```

3. Установите зависимости:
```powershell
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

## Использование

При запуске отобразится меню:

```
--- Меню ---
1. GET-запрос по URL
2. Информация о стране
3. Случайная собака
0. Выход
```

### 1. GET-запрос по URL
Введите URL и опционально query-параметры в формате `key1=value, key2=value`

### 2. Информация о стране
Введите название страны (например, `Italy`, `Germany`, `Russia`)

### 3. Случайная собака
Получает случайное изображение собаки из API `dog.ceo`
