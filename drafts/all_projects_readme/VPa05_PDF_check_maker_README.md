# Генератор PDF-счетов

Приложение для создания профессиональных PDF-счетов из данных в CSV или JSON формате.

---

## Быстрый старт

1. **Запуск программы:**
   - Дважды кликните по файлу `generate_invoice.bat`
   - Либо запустите из командной строки:
     ```powershell
     .\generate_invoice.bat
     ```

2. **Следуйте подсказкам в окне:**
   - Выберите файл с данными (CSV или JSON)
   - Выберите шаблон счета (HTML)
   - Выберите конкретный счет из списка

3. **Результат:**
   - PDF-файл автоматически сохраняется в папке `output/`
   - PDF сразу открывается в программе просмотра по умолчанию

## Формат данных

### CSV-файл

Создайте CSV-файл со следующими столбцами:

| Столбец | Описание | Пример |
|---------|----------|--------|
| `invoice_id` | Номер счёта | `INV-001` |
| `customer_name` | Название организации / ФИО | `ООО «Ромашка»` |
| `date` | Дата счёта | `2026-05-01` |
| `currency` | Валюта (по умолчанию ₽) | `₽` |
| `product` | Наименование товара/услуги | `Консультация (час)` |
| `price` | Цена за единицу | `2500` |
| `qty` | Количество | `4` |
| `tax_rate` | Ставка НДС в % | `20` |
| `notes` | Примечания | `Оплата в течение 14 дней` |

**Пример (sample_invoices.csv):**
```csv
invoice_id,customer_name,date,currency,product,price,qty,tax_rate,total,notes
INV-001,ООО «Ромашка»,2026-05-01,₽,Консультация (час),2500,4,20,14940,Оплата в течение 14 календарных дней.
INV-002,ИП Иванов П.С.,2026-05-03,₽,Лицензия на ПО (1 мес.),3200,1,0,3200,Без НДС (упрощённая система).
```

### JSON-файл

```json
{
  "invoices": [
    {
      "invoice_id": "INV-001",
      "customer_name": "ООО «Ромашка»",
      "date": "2026-05-01",
      "currency": "₽",
      "product": "Консультация (час)",
      "price": 2500,
      "qty": 4,
      "tax_rate": 20,
      "notes": "Оплата в течение 14 календарных дней."
    }
  ]
}
```

## Создание новых счетов

### Шаг 1: Добавьте данные

1. Откройте файл `data/sample_invoices.csv` в Excel или текстовом редакторе
2. Добавьте новую строку с данными вашего счёта
3. Сохраните файл

**Или создайте новый CSV-файл:**
1. Скопируйте `sample_invoices.csv`
2. Переименуйте в ваше имя файла (например, `my_invoices.csv`)
3. Отредактируйте данные

### Шаг 2: Запустите генератор

1. Дважды кликните `generate_invoice.bat`
2. Выберите ваш файл данных
3. Выберите шаблон (формальный или современный)
4. Выберите номер счёта из списка

### Шаг 3: Получите PDF

- Файл сохраняется в `output/INV-XXX.pdf`
- Открывается автоматически

## Изменение дизайна счетов

### Выбор шаблона

В папке `templates/` есть два готовых шаблона:

| Шаблон | Стиль | Когда использовать |
|--------|-------|-------------------|
| `invoice_formal.html` | Строгий, классический | Официальные документы, бухгалтерия |
| `invoice_modern.html` | Современный, с градиентом | Презентации, клиенты |

### Создание своего шаблона

1. Скопируйте один из шаблонов в `templates/`
2. Откройте в текстовом редакторе (Notepad++, VS Code)
3. Измените HTML и CSS по вашему усмотрению

**Доступные переменные в шаблоне:**

| Переменная | Описание | Пример |
|------------|----------|--------|
| `{{ invoice_id }}` | Номер счёта | `INV-001` |
| `{{ customer_name }}` | Название заказчика | `ООО «Ромашка»` |
| `{{ date }}` | Дата | `2026-05-01` |
| `{{ currency }}` | Валюта | `₽` |
| `{{ product }}` | Товар/услуга | `Консультация` |
| `{{ qty }}` | Количество | `4` |
| `{{ price }}` | Цена за единицу | `2 500,00 ₽` |
| `{{ line_total }}` | Сумма строки | `10 000,00 ₽` |
| `{{ subtotal_display }}` | Итого без НДС | `10 000,00 ₽` |
| `{{ tax_rate_display }}` | Ставка НДС | `20 %` |
| `{{ tax_amount_display }}` | Сумма НДС | `2 000,00 ₽` |
| `{{ total_display }}` | Всего к оплате | `12 000,00 ₽` |
| `{{ notes }}` | Примечания | `Оплата в течение 14 дней` |

## Решение проблем

### ❌ Ошибка: "Виртуальное окружение не найдено"

**Причина:** Отсутствует папка `.venv`

**Решение:**
```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### ❌ Ошибка: "Не удалось создать PDF"

**Причина:** Отсутствуют шрифты

**Решение:**
- Убедитесь, что в папке `fonts/` есть файл `DejaVuSans.ttf`
- Шрифт уже есть в проекте, не удаляйте его

### ❌ Ошибка: "Файл CSV не читается"

**Причина:** Неправильная кодировка

**Решение:**
- Сохраните CSV в кодировке **UTF-8 с BOM**
- В Excel: Файл → Сохранить как → Тип файла: "CSV (разделители-запятые UTF-8)"

### ❌ PDF открывается некорректно

**Причина:** Нет программы для просмотра PDF

**Решение:**
- Установите Adobe Reader, Foxit Reader или используйте браузер
- Файл можно открыть в любом PDF-reader

## Расчёт сумм

Программа автоматически рассчитывает:

```
line_total = price × qty
subtotal = сумма всех line_total
tax_amount = subtotal × tax_rate / 100
total = subtotal + tax_amount
```

**Пример:**
- Цена: 2 500 ₽
- Количество: 4
- НДС: 20%

```
line_total = 2 500 × 4 = 10 000 ₽
subtotal = 10 000 ₽
tax_amount = 10 000 × 20 / 100 = 2 000 ₽
total = 10 000 + 2 000 = 12 000 ₽
```
