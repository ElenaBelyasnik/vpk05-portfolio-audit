# 📝 NoteCaddy

**Умный помощник для заметок** — работает в двух режимах: CLI (терминал) и Web (браузер).

---

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install flask rich
```

### Запуск

```bash
# Веб-режим (по умолчанию)
python notecaddy.py

# Или явно
python notecaddy.py web
```

---

## 💻 Режим CLI (Командная строка)

### Команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `add` | Создать заметку | `python notecaddy.py add "Купить молоко"` |
| `list` | Показать все заметки | `python notecaddy.py list` |
| `delete` | Удалить заметку | `python notecaddy.py delete 1` |
| `web` | Запустить веб-сервер | `python notecaddy.py web` |
| `--help` | Показать справку | `python notecaddy.py --help` |

## 🌐 Режим Web (Веб-интерфейс)

### Запуск

```bash
python notecaddy.py web
```

**Вывод:**
```
============================================================
  NoteCaddy v1.0.0
  Веб-сервер запущен
============================================================

  Откройте в браузере: http://127.0.0.1:5000

  Нажмите Ctrl+C для остановки
```

### Открыть в браузере

Перейди по адресу: **http://localhost:5000**

### Функции веб-интерфейса

1. **Создание заметки**
   - Введи текст в форму
   - Нажми кнопку **"💾 Сохранить"**
   - Заметка автоматически структурируется

2. **Просмотр заметок**
   - Все заметки отображаются в виде карточек
   - Показаны: исходный текст, обработанный текст, краткий итог
   - Каждая заметка имеет уникальный ID и дату создания

3. **Удаление заметки**
   - Нажми кнопку **"🗑️ Удалить"** на любой заметке
   - Подтверди удаление в диалоговом окне

## 🧠 Как работает обработка текста

NoteCaddy автоматически анализирует текст и выделяет:

| Тип | Ключевые слова | Пример |
|-----|----------------|--------|
| 📌 **Задачи** | купить, нужно, сделать, надо | "Купить молоко" |
| 🤝 **Встречи** | встреча, обсудить, созвон | "Встреча с Анной" |
| 📝 **Другое** | остальной текст | "Изучить документацию" |
| ⏰ **Время** | формат HH:MM | "15:00", "18:30" |
| 📅 **Даты** | завтра, сегодня, дни недели | "завтра", "понедельник" |

### Пример обработки

**Ввод:**
```
Купить продукты молоко хлеб яйца. Завтра встреча с Анной в 15:00, обсудить проект.
```

**Результат:**
```
📌 **Задачи**:
  • Купить продукты молоко хлеб яйца.

🤝 **Встречи и обсуждения**:
  • Завтра встреча с Анной в 15:00, обсудить проект.


⏰ **Время**: 15:00
📅 **Даты**: завтра
```

## 📁 Структура данных

Заметки сохраняются в файле `notes.json`:

```json
[
  {
    "id": 1,
    "created_at": "2026-05-01 23:00:31",
    "raw_text": "Купить продукты молоко хлеб яйца. Завтра встреча с Анной в 15:00, обсудить проект.",
    "processed_text": "📌 **Задачи**:\n  • Купить продукты молоко хлеб яйца.\n\n🤝 **Встречи и обсуждения**:\n  • Завтра встреча с Анной в 15:00, обсудить проект.\n\n⏰ **Время**: 15:00\n📅 **Даты**: завтра",
    "summary": "Создано: 1 задача(и), 1 встреча(и) | время: 15:00, даты: завтра"
  }
]
```

- **Python 3.8+**

## ⚠️ Обработка ошибок

| Ситуация | Реакция |
|----------|---------|
| Файл `notes.json` не существует | Создаётся автоматически |
| Попытка удалить несуществующую заметку | Сообщение об ошибке |
| Пустой текст заметки | Предупреждение в веб-интерфейсе |
| Ошибка сохранения | Сообщение с описанием проблемы |

## 🎯 Советы по использованию

### CLI режим
- Идеален для **быстрых заметок** из терминала
- Подходит для **скриптов и автоматизации**
- Красивый вывод через Rich (установи для лучшего опыта)

### Web режим
- Удобно для **ежедневного использования**
- **Визуальный интерфейс** для просмотра всех заметок
- Доступен **из любой точки сети** (настрой host/порт)

### Общие советы
- Используй **конкретные формулировки** для лучшего структурирования
- Добавляй **время и даты** для важных событий
- Регулярно **очищай старые заметки** через delete

## 📞 Поддержка

Приложение разработано как **самодостаточный инструмент**. Все данные хранятся локально в `notes.json`.
