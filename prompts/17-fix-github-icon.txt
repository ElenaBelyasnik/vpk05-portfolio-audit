На главной странице сайта (`site/templates/index.html`) в блоке контактов кнопка GitHub сейчас использует эмодзи 🐙. Нужно заменить её на настоящую SVG-иконку GitHub (черный силуэт кота в круге).

1. Скачай или найди официальную SVG-иконку GitHub (например, из просторов интернета или сгенерируй стандартный путь SVG).
2. В `site/templates/index.html` найди кнопку с текстом "GitHub". Замени эмодзи 🐙 на встроенный SVG-код иконки. Например:

В site/static/css/style.css добавь правило, чтобы SVG-иконки выравнивались по центру с текстом:
