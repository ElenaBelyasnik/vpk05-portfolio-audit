# PassMan CLI

Простое CLI-приложение на Python для хранения паролей в SQLite с шифрованием (`Fernet`) и мастер-паролем (SHA-256).

## Возможности

- Мастер-пароль для входа (хранится как SHA-256 хеш)
- Шифрование паролей через `cryptography.fernet.Fernet`
- Локальный ключ в файле `.key` (создается автоматически)
- Хранение данных в `passwords.db` (SQLite3)
- Интерактивное меню с действиями: добавить, получить, показать список, удалить, сгенерировать пароль

## Требования

- Python 3.10+
- Установленный `pip`

## Установка

```bash
pip install -r requirements.txt
```

Если команда `python` не работает в Windows, используйте `py`:

```bash
py -m pip install -r requirements.txt
```

## Первый запуск

При первом запуске приложение:

1. Создает таблицы в SQLite (если их нет)
2. Генерирует файл `.key` (если его нет)
3. Просит создать мастер-пароль

Запуск:

```bash
python passman.py
```

После запуска приложение покажет меню с пунктами:

1. Добавить новый пароль
2. Получить пароль
3. Список всех паролей
4. Удалить пароль
5. Сгенерировать пароль
6. Выход

## Примечания по использованию

- Ввод мастер-пароля и обычного пароля скрыт (символы не отображаются) — это нормально.
- При добавлении записи можно выбрать автогенерацию пароля или ввести пароль вручную.
- В генераторе можно выбрать длину (8-64), наборы символов и исключить похожие символы (`0/O`, `l/I`).
- После каждого действия есть пауза `Нажмите Enter для продолжения...`.

## Что хранится

- `passwords.db` — база SQLite
- `.key` — ключ шифрования Fernet

Не удаляйте `.key`, иначе существующие пароли в БД нельзя будет расшифровать.
