# CLI Greet

Простое CLI приложение на Python, которое бесконечно запрашивает имя пользователя и приветствует его.

## Установка окружения

```bash
python -m venv venv
```

## Активация окружения

**Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**
```cmd
venv\Scripts\activate.bat
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

## Использование

1. Запустите скрипт
2. Введите своё имя
3. Получите приветствие
4. Повторяйте бесконечно или нажмите `Ctrl+C` для выхода
