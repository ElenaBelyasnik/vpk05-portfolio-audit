# Prompt Testing Module

Модуль для тестирования промптов через OpenAI-совместимый API (GenAPI).
Каждый промпт запускается 2 раза с разными значениями temperature (0.2 и 0.7),
результаты сохраняются в JSON и генерируется подробный Word-отчёт.

## Структура проекта

- `prompts/` — файлы промптов в формате JSON
- `drafts/` — черновики и заметки
- `prompt_chat.py` — основной модуль тестирования
- `test_result.json` — автоматически создаваемый файл с результатами тестов
- `test_result.docx` — автоматически создаваемый Word-отчёт

## Установка

1. Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

2. Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

2. Заполните `OPENAI_API_KEY` в файле `.env`.

## Использование

Запустите модуль:

```powershell
python prompt_chat.py
```

Модуль выполнит:
1. Загрузит все промпты из папки `prompts/`
2. Выведет список промптов с описанием
3. Последовательно прогонит каждый промпт 2 раза (temperature = 0.2 и 0.7)
4. Сохранит результаты в `test_result.json`
5. Сгенерирует отчёт `test_result.docx`

## Структура отчёта `test_result.docx`

1. **Заголовок** — дата запуска, модель, количество тестов
2. **Сводная таблица** — все запуски с параметрами и временем генерации
3. **Детали по каждому промпту:**
   - Информация (ID, название, категория, описание, версия)
   - Вопрос пользователя
   - Сравнительная таблица temperature 0.2 vs 0.7
   - Ответы модели для каждого temperature
   - Анализ различий:
     - Расход токенов
     - Длина ответа
     - Время генерации
     - Характер ответов
   - Выводы по промпту
4. **Общие выводы** — влияние температуры на результаты

## Требования

- Python 3.10+
- OpenAI API ключ (GenAPI)
