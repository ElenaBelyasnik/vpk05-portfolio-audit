# Конвертер валют

Программа для работы с курсами валют: получение курсов, конвертация между валютами, кэширование данных.

## Функциональность

- **Просмотр доступных валют** — список валют в кэше
- **Конвертация валют** — перевод суммы из одной валюты в другую
- **Обновление курсов** — загрузка актуальных данных с API
- **Кэширование** — сохранение данных в файл (валидация кэша 24 часа)
- **Валидация валют** — проверка кодов валют перед конвертацией

## Установка

1. Клонируйте репозиторий:

   ```bash
   cd VPd02
   ```

2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```

3. Активируйте окружение:

     ```powershell
     .\venv\Scripts\Activate.ps1
     ```

     ```bash
     source venv/bin/activate
     ```

4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

### Интерактивный режим

```bash
python currency.py
```

Меню:
1. Показать доступные валюты
2. Конвертировать валюту
3. Обновить курсы валют
4. Выход

### CLI режим — получение курсов

```bash
python currency.py USD
```

Выведет курсы USD к RUB, EUR, GBP.

### CLI режим — конвертация

```bash
python currency.py convert USD EUR 100
```

Вывод: `100.0 USD = 86.3292 EUR` (с 4 знаками после запятой)

## API

Используется бесплатное API: `https://open.er-api.com/v6/latest/{base}`

## Формат данных

Курсы сохраняются в `currency_rate.json` (UTF-8, indent=4):

```json
{
    "USD": {
        "rates": {
            "RUB": 72.41,
            "EUR": 0.86,
            "GBP": 0.74
        }
    }
}
```
