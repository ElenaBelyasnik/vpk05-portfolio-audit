# 💧 Water Reminder Bot

Telegram-бот для напоминаний о питье воды и отслеживания статистики потребления.

## 📝 Описание

Бот помогает не забывать пить воду в течение дня. Он:
- Раз в час отправляет напоминание о воде
- Позволяет записывать выпитые стаканы одной кнопкой
- Показывает статистику за все дни с возможностью просмотра прошлых дней
- Хранит данные в локальном JSON-файле

## ✨ Возможности

- 💧 **Кнопка «Пить»** — добавляет 1 стакан воды за сегодняшний день
- 📊 **Кнопка «Статистика»** — показывает статистику за все дни с пагинацией
- ⏰ **Автоматические напоминания** — раз в час бот присылает напоминание
- 💾 **Сохранение данных** — вся статистика хранится в `data.json`

## 🚀 Запуск

### Предварительные требования

- Python 3.8+
- Токен бота от [@BotFather](https://t.me/BotFather)

### Установка

1. Клонировать репозиторий (или скачать файлы)

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Создать переменную окружения с токеном бота:
```bash
# Linux/macOS
export BOT_TOKEN="ваш_токен_от_BotFather"

# Windows (PowerShell)
$env:BOT_TOKEN="ваш_токен_от_BotFather"
```

4. Запустить бота:
```bash
python bot.py
```

## 🎮 Использование

После запуска бота в Telegram:

1. Нажмите `/start` для приветствия
2. Используйте кнопки внизу экрана:
   - **💧 Пить** — записать выпитый стакан
   - **📊 Статистика** — посмотреть статистику с пагинацией по дням

## 📊 Формат данных

Данные хранятся в `data.json` в следующем формате:

```json
{
  "user_12345": {
    "2026-05-15": 5,
    "2026-05-14": 3,
    "2026-05-13": 7
  }
}
```

Где:
- `user_12345` — уникальный идентификатор пользователя Telegram
- Ключи — даты в формате `YYYY-MM-DD`
- Значения — количество выпитых стаканов за этот день
