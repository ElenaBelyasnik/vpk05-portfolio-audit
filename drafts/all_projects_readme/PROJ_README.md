# Консольный калькулятор факториала

Простое приложение на Python для вычисления факториала неотрицательного целого числа.

## Требования

- Python 3.x

## Запуск

1. Откройте терминал в папке проекта.
2. Выполните команду:

```bash
python factorial.py
```

## Как использовать

1. После запуска введите неотрицательное целое число.
2. Нажмите Enter.
3. Программа выведет факториал введенного числа.

## Пример

```text
Введите неотрицательное целое число: 5
Факториал числа 5 = 120
```

## Обработка ошибок

- Если ввести не целое число, программа покажет сообщение об ошибке.
- Если ввести отрицательное число, программа сообщит, что факториал для него не определен.
