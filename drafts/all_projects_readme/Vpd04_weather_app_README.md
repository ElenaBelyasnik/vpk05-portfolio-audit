# VK-бот погоды с Yandex Weather API

Telegram-подобный бот для ВКонтакте, предоставляющий прогноз погоды через Yandex Weather API.

## Возможности бота

- 🌤 **Погода сейчас** — текущая погода по городу, координатам или геолокации
- 📅 **Прогноз на 5 дней** — подробный прогноз с дневными и ночными температурами
- 🌫 **Расширенный режим** — погода с качеством воздуха и видимостью
- ℹ️ **Помощь** — справка по использованию

### Поддерживаемые форматы запросов

Во всех режимах можно:
- Ввести название города (Москва, Санкт-Петербург, Казань и др.)
- Ввести координаты: `55.7558, 37.6173`
- Прикрепить точку на карте (геолокация)

## Установка

1. **Клонируйте репозиторий:**
```powershell
git clone <repo-url>
cd vk-weather-bot
```

2. **Создайте виртуальное окружение:**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

3. **Установите зависимости:**
```powershell
pip install -r requirements.txt
```

4. **Настройте переменные окружения:**
```powershell
cp .env.example .env
```

Заполните `.env`:
```
API_KEY=ваш_yandex_weather_api_key
VK_BOT_TOKEN=ваш_vk_bot_token
```

## Запуск бота

```powershell
python vk_bot.py
```

## Запуск консольной версии

```powershell
# Интерактивное меню
python weather_app.py

# Быстрый запрос
python weather_app.py --city Москва
python weather_app.py --city Москва --days 5
python weather_app.py --coords 55.75 37.61 --days 3 --extended
python weather_app.py --read
```

## Получение API ключей

### Yandex Weather API
1. Зайдите в [Кабинет разработчика Яндекс](https://developer.tech.yandex.ru/)
2. Создайте новый проект
3. Подключите API «Погода»
4. Скопируйте API ключ

### VK Bot Token
1. Зайдите в [Управление сообществами VK](https://vk.com/editapp?act=create)
2. Создайте сообщество или используйте существующее
3. Перейдите в **Управление → Работа с API**
4. Создайте ключ с правами на сообщения
5. Включите **Сообщения сообщества** → **Настройки для сообщений** → **Включены**

## Особенности реализации

### Система состояний
- Простой словарь `_user_states` вместо `vkbottle.StateGroup`
- Состояния: `"weather"`, `"forecast"`, `"extended"`
- Автоматическая очистка после обработки

### Кэширование (консольная версия)
- Данные сохраняются в `weather_cache.json`
- TTL кэша: 3 часа
- Проверка совпадения города и количества дней

### Повторные запросы (Retry)
- При ошибке 429 или сетевых ошибках — до 3 повторов
- Экспоненциальная задержка: 1с, 2с, 4с

### Геолокация
- VK отправляет карты как `message.geo`
- Поддержка координат в формате `55.7558, 37.6173`
- Проверка диапазона координат
